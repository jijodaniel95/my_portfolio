Case studies

A closer look at three projects

What the problem was, how I approached it, and what changed as a result.

40% lower infrastructure cost

Infosys · 2022 to 2024

Moving 100+ microservices from OpenShift to Google Cloud

Problem
A large estate of Java microservices ran on OpenShift. Infrastructure costs were high, and the services had to move to Google Cloud without interrupting the applications that depended on them.
Approach
Containerized services with Docker and moved them onto Google Kubernetes Engine. I developed Go proxies for the GCP transformation so traffic kept flowing during cut-over, and built NGINX-based routing to spread load at peak times. I also played a key developer role in the OpenShift to Anthos migration.
Result
More than 100 services migrated, infrastructure costs down by an estimated 40%, and high availability on GKE. The work earned three Infosys Insta Awards.
  • GKE
  • Anthos
  • Docker
  • Go
  • NGINX
  • Spring Boot
80+ pipelines migrated

Royal Bank of Canada · 2025 to now

Rebuilding CI/CD on GitHub Actions

Problem
Delivery for a set of banking services depended on Jenkins pipelines. Releases were slower than they needed to be, and every pipeline had to keep meeting the bank's compliance and security standards.
Approach
I led the migration of more than 80 pipelines from Jenkins to GitHub Actions, and optimized deployment workflows along the way while keeping the build and release steps aligned with banking standards.
Result
Release time came down and deployments became more reliable, with every pipeline on one modern platform.
  • GitHub Actions
  • Jenkins
  • CI/CD
  • Spring Boot

Royal Bank of Canada · 2025 to now

Event-driven services for financial transactions

Problem
High-volume transaction systems had to process large-scale financial data reliably, with low latency and no single point of failure between services.
Approach

Result
Reliable asynchronous communication across services, faster response times in critical paths, and fault-tolerant processing of high-throughput financial data.
